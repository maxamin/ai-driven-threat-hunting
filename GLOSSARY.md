# Glossary

- **Threat hunting:** proactive, hypothesis-driven search for adversary activity not caught by existing detections.
- **Hypothesis:** a testable statement naming a behaviour, its observable evidence and the data that would show it.
- **ATT&CK:** MITRE's knowledge base of adversary tactics and techniques, published as STIX data.
- **Sigma:** a vendor-neutral YAML format for detection rules, convertible to SIEM query languages.
- **KQL:** Kusto Query Language, used by Microsoft Sentinel, Defender XDR and Azure Data Explorer.
- **SPL:** Splunk's Search Processing Language.
- **Positive test:** running a query against known-malicious events to confirm it matches.
- **Negative test:** running a query against clean baseline data to measure false positives.
- **Schema grounding:** giving the model the real table and field names so it does not invent them.
- **Stack counting:** counting value frequencies across a fleet to surface rare outliers.
- **Beaconing:** regular, automated outbound connections typical of command-and-control.
- **Log injection (LLM):** attacker text placed in log fields to steer an AI analyst.
- **Alert budget:** a fixed daily number of alerts the team can review, used to tune thresholds.
