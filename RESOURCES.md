# Resources

## Tools

- [Sigma](https://github.com/SigmaHQ/sigma), [pySigma](https://github.com/SigmaHQ/pySigma), [sigma-cli](https://github.com/SigmaHQ/sigma-cli) — vendor-neutral detection rules and converters.
- [Kusto Query Language parser](https://github.com/microsoft/Kusto-Query-Language) — offline KQL parsing.
- [Hayabusa](https://github.com/Yamato-Security/hayabusa), [Chainsaw](https://github.com/WithSecureLabs/chainsaw) — EVTX hunting with Sigma.
- [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team) — small, ATT&CK-mapped tests for positive validation.
- [Zeek](https://zeek.org/), [RITA](https://github.com/activecm/rita) — network telemetry and beacon analysis.
- [Velociraptor](https://github.com/Velocidex/velociraptor), [osquery](https://osquery.io/) — endpoint collection.
- [mitreattack-python](https://github.com/mitre-attack/mitreattack-python), [ATT&CK STIX data](https://github.com/mitre-attack/attack-stix-data).
- [TRAM](https://github.com/center-for-threat-informed-defense/tram) — threat report to ATT&CK mapping.
